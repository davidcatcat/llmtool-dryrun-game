# llmtool-dryrun-game

A tiny static click game used only as an isolated dry-run target for llmtool
cross-repository workflow testing (davidcattoolsproject #396 / #1230 D2).

- Open `index.html` in a browser to play.
- Run the tests with `npm test` (Node 18+, no dependencies).

This repository has no CI runners. Nothing here is merged by llmtool.
